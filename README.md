# 🚀 LifePilot AI

> Your Autonomous Personal Productivity AI Agent

## 📖 Overview

LifePilot AI is an intelligent AI assistant designed to automate everyday tasks using **n8n**, **Gemini AI**, and **Google Workspace APIs**.

It can help users manage their schedule, remember important information, automate repetitive tasks, and provide smart AI-powered assistance.

---

## ✨ Features

- 🧠 AI Task Planning
- 📅 Google Calendar Integration
- 📧 Gmail Automation
- 📝 Smart Notes & Memory
- 📊 Google Sheets Integration
- 🔔 Daily Reminders
- 🤖 AI Decision Making

---

## 🛠️ Tech Stack

- n8n
- Gemini AI
- Google Calendar API
- Gmail API
- Google Sheets API
- JavaScript
